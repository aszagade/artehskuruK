KURUKSHETRA is an enterprise AI command center for IDeaS Service Delivery.

1. SANJAYA — conversational command center
2. SEAL — self-adaptive learning memory
3. Multi-RAG — enterprise retrieval engine

5. Governance — permissions, ownership, audit
