# KURUKSHETRA Engineering Charter

## Identity

KURUKSHETRA is the enterprise AI command center for IDeaS Service Delivery.

SANJAYA = communication layer.
SEAL = adaptive learning memory.

## Architecture First

* Never create duplicate folders.
* Extend existing modules before creating new ones.
* Never move or rename files unless explicitly instructed.
* Preserve backward compatibility.

## Knowledge Integrity

* Never invent IDeaS terminology.
* Unknown acronyms become UNKNOWN.
* Every factual answer must reference repository evidence whenever available.

## Development Workflow

* Explain architecture before large implementations.
* Keep every task suitable for one Git commit.
* Never perform Git commits automatically.
* Always propose a Conventional Commit message.

## Code Standards

* Python 3.13
* Modular design
* Strong typing where practical
* Logging over print
* Configuration separated from code
