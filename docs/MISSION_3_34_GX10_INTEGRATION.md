# Mission 3.34 — SANJAYA GX10 LLM Integration

## Date
August 28, 2026

## Objective
Integrate SANJAYA with the existing GX10 LLM endpoint so that retrieved organizational knowledge is synthesized into natural-language answers with citations, while preserving authorization, grounding, and abstention behavior.

## Architecture

```
User Question
     │
     ▼
┌─────────────────────────────────────────────┐
│  SANJAYA Planner                           │
│  (intent classification, strategy selection)│
└────────────────────┬────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────┐
│  Retrieval Layer                            │
│  (BM25 / Vector / Hybrid + VisibilityFilter)│
└────────────────────┬────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────┐
│  AnswerGenerator                            │
│  ├── Evidence validation (relevance check)  │
│  ├── Conflict detection                     │
│  ├── LLM first path (GX10) ← NEW            │
│  │   └── Evidence + Query → GX10 → Answer   │
│  ├── Extractive fallback                    │
│  │   └── Sentence extraction → Answer       │
│  ├── Citations / Provenance preserved       │
│  └── Abstention when evidence insufficient  │
└─────────────────────────────────────────────┘
```

## Failure/Abstention Behavior

| Scenario | Behavior |
|----------|----------|
| GX10 not configured | Falls back to extractive answer |
| GX10 timeout | Falls back to extractive answer |
| GX10 HTTP error | Falls back to extractive answer |
| No evidence found | Abstains (before LLM call) |
| Evidence irrelevant | Abstains (relevance check) |
| Unauthorized evidence | Abstains |
| LLM returns empty | Falls back to extractive |
| LLM returns answer | Uses LLM answer + citations |

## Answer Flow

1. **Build evidence** from retrieval results
2. **Validate** evidence count and authorization
3. **Check relevance** (query terms vs evidence)
4. **Detect conflicts** in evidence
5. **Build citations** and assess quality
6. **Try LLM first** (if available): query + evidence → GX10 → natural answer
7. **Extractive fallback** (if LLM unavailable/failed): sentence extraction
8. **Abstain** if confidence too low
9. **Return** with citations, provenance, limitations

## What Remains Before Enterprise Deployment

1. **Retry/rate-limiting** — GX10 client has no retry logic yet
2. **Streaming** — No streaming support for long answers
3. **Prompt refinement** — System prompt may need tuning for specific enterprise domains
4. **Model selection** — Could route different query types to different models
5. **Caching** — No response caching for repeated queries
6. **Token management** — No truncation of evidence to fit model context window
7. **Evaluation** — Need human evaluation of LLM answer quality vs extractive
8. **A/B comparison** — Need framework to compare LLM vs extractive answers
